# Fundamentals Exercises

- [exercise_01_syntax.py](exercise_01_syntax.py): fix indentation and comparison errors.

## Data Types

- [exercise_02_data_types.py](exercise_02_data_types.py): implement type-safe numeric comparison.

## Collections

## Functions

## Comprehensions

## Modules
