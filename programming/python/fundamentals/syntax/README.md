# Syntax

## Problem

Before writing correct Python, you need to know how the interpreter parses and executes code.

## What Is It?

Python's syntax rules: indentation-based blocks, statements, expressions, and comments.

## Why Does It Matter?

Indentation errors and statement/expression confusion are the most common early mistakes.

## How It Works

Python uses whitespace indentation instead of braces to define blocks, and executes top-level statements in order.
